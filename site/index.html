Everything Agents Need to Run Safely

🛡

Risk Classification

Built-in rules engine auto-classifies actions as LOW/MEDIUM/HIGH/CRITICAL. Destructive SQL, bulk operations, and file deletions are caught before execution.

💰

Budget Control & Forecasting

Per-action cost tracking, budget limits, burn-rate analysis, and exhaustion prediction. Know exactly when your budget will run out.

⏪

Instant Rollback

Deep-copy state snapshots let you undo any action with a single call. Auto-snapshots any tool you give capture/restore functions.

⚡

Circuit Breaker

Auto-disable tools that fail repeatedly. CLOSED/OPEN/HALF_OPEN states with configurable thresholds and recovery probes.

👤

Human-in-the-Loop

Approval workflows with configurable timeout, auto-deny, callback-based approval, and escalation chains for high-risk actions.

🔒

Agent Capabilities

Fine-grained allowlist/denylist per agent. Argument constraints, cost limits, and time-based access schedules.

🔍

Distributed Tracing

OpenTelemetry-style spans for every action. Nested spans, JSON span export, trace grouping.

💥

Chaos Engineering

Fault injection (errors, latency, timeouts, corruption) with probability control, conditional triggers, and wildcard rules.

📊

Agent Scoring

Safety/reliability/efficiency/risk scoring (0-100) with A-F grades. Multi-agent pool rankings and leaderboards.

📜

Compliance Reports

Audit reports from SQLite logs (inputs for SOC2/GDPR processes). Anomaly detection, risk breakdown, JSON/HTML export.

🚦

Rate Limiting

Sliding-window counters: global RPM/RPH and per-tool limits. Auto-prune for memory efficiency.

🛠

5 Framework Integrations

OpenAI, Anthropic Claude, LangChain, CrewAI, Microsoft AutoGen. Zero import overhead — frameworks are optional.

🧠

Smart Model Routing

Automatically classifies task complexity and routes to the cheapest capable model. 60-90% cost savings without sacrificing quality.

🚨

Cost Anomaly Detection

Z-score based spending spike detection, infinite loop detection, rate spike monitoring, and burn rate alerts with real-time callbacks.

📈

FinOps Dashboard

Real-time 5-tab web UI: Overview, FinOps (cost breakdown), Estimation (self-improving predictions), Routing (model stats), and Alerts (anomaly monitoring).

⏱

Execution Timeout

Hard deadline enforcement for tool calls. Per-tool timeout overrides. Stops waiting on hanging calls before they burn budget silently.

🔒

Idempotency Guard

Prevents duplicate execution on retry. Content-hash or client-supplied keys, TTL expiry, pluggable backends (in-memory or Redis). Works across distributed processes.

🔍

Output Validation

Validates, redacts, or blocks tool outputs before they reach the agent. Built-in PII detection. Custom pattern rules.

🔄

Fallback Routing

When a tool is circuit-broken, auto-routes to a cheaper/safer alternative. Configurable conditions and max-fallback limits.

📊

Execution Quotas

Daily, weekly, and monthly call limits per tool or globally. Long-term caps that complement sliding-window rate limiting.

🔮

Pre-execution Cost Estimation

Know the cost BEFORE you run. Best/expected/worst case predictions with confidence scores. Self-improving — gets smarter the more your agents run.

🔎

Rollback Transparency

Every tool call carries a reversible flag. Auto-inferred from snapshot functions or set explicitly. Your agent knows what can be undone before acting.

Different Layers, Not Competitors

WarderBox doesn't replace LangChain or Guardrails AI — it fills the gap neither covers. They work together.

🧠

LangChain

Runs the agent

Chains, RAG, memory, tool calling, agent orchestration. Decides what to do.

✅

Guardrails AI

Validates LLM text

JSON schema, hallucination checks, format validation. Controls what the LLM says.

🛡️

WarderBox

Controls tool execution

Budget, rollback, timeout, circuit breaker, idempotency, quotas. Controls what the agent does.

Use LangChain to build your agent → WarderBox to keep it safe → Guardrails to validate its text. All three via shield_langchain_tools()
